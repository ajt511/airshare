一、这是什么
----------------------------------------------------------------
一款免费的手机间文件传输应用，核心特色是「隔空手势」：

  在屏幕前张开手掌 → 握拳（抓住内容）→ 侧倾手机选设备
  → 张开手掌（发送）

同时提供两种传输通道：
  1. 互传联盟通道：直接发给小米/OPPO/vivo 等手机的「原生互传」，
     对方不需要安装本应用（发送端需 Shizuku 授权一次）
  2. 局域网通道：同一 Wi-Fi 或热点下双方都装了本应用即可互传，
     支持文件与文本，无需 Wi-Fi Direct

----------------------------------------------------------------
二、安装前须知
----------------------------------------------------------------
1. 支持系统：Android 12（API 31）及以上
   - 小米（澎湃OS / MIUI）：支持
   - OPPO / 一加 / realme（ColorOS）：支持
   - 华为 / 荣耀 HarmonyOS 4.x（含鸿蒙 4.2）：支持
     * 鸿蒙 4.2 安装前必须关闭「纯净模式」：
       设置 → 系统和更新 → 纯净模式 → 关闭
   - 纯血鸿蒙（HarmonyOS NEXT / 5.0）：不支持安装 APK

2. 覆盖安装注意：不同次构建的安装包签名不同，无法直接覆盖升级。
   升级前先卸载旧版。可通过「设置 → 应用 → 手势互传 → 版本号」
   确认当前版本（如 1.3.4-beta）。

3. 安装包文件名说明：文件名自带版本后缀，例如
   airshare-universal-1.3.4-beta.apk（全机型通用版）
   airshare-arm64-1.3.4-beta.apk（仅 arm64 机型，体积更小）
   2019 年之后的手机选 arm64 版即可；不确定就装 universal 版。

----------------------------------------------------------------
三、安装步骤
----------------------------------------------------------------
1. 将 APK 复制到手机（数据线 / 微信文件传输助手 / 蓝牙均可）
2. 在手机上点击 APK 安装
   - 提示「未知来源」时：允许该来源安装
   - 鸿蒙 4.2：先关闭纯净模式（见二-1）
3. 安装完成，桌面出现「手势互传」图标

----------------------------------------------------------------
四、首次启动与权限设置
----------------------------------------------------------------
首次打开应用会依次申请权限，请全部允许：

  [必开] 附近设备（蓝牙/局域网发现设备）
  [必开] 通知（传输进度提示）
  [必开] 相机（仅隔空手势界面使用，其他界面不调用）

建议完成的项目（在应用设置页）：

  [推荐] 厂商自启动：设置页 →「设备兼容（测试版）」→ 自启动设置。
         应用会自动识别你的系统（澎湃OS/ColorOS/鸿蒙）并跳转到
         对应页面。不开启的话后台接收容易被系统杀掉。
  [推荐] 电池优化白名单：「设备兼容（测试版）」→ 电池优化。
  [小米专属] 后台弹出界面：「设备兼容（测试版）」→ 后台弹出界面。
         「看图即手势」的悬浮条能否弹出全靠它。
  [可选] Shizuku（仅互传联盟通道「发送」需要；接收不需要）：
         1. 安装 Shizuku 应用并启动（无线调试或电脑激活）
         2. 本应用设置页 →「增强模式」→ 授权
  [可选] 保存位置：设置 → 保存到 → 选自定义文件夹（默认
         Download/Easy Share）

五、发送文件的三种方式
----------------------------------------------------------------
方式一：主页进入手势界面
  打开应用 → 点「隔空手势传输」卡片 → 点「选择要抓取的文件」
  → 勾选内容 → 做手势（见第六节）

方式二：系统分享面板（推荐给单个文件/图片）
  在相册、微信、文件管理器里点「分享」→ 选「手势互传」
  → 设备列表里可点选目标，或点底部「手势发送」进入手势界面
  → 此时内容已经"抓在手里"，直接做手势即可

方式三：摇一摇（需先在设置开启）
  设置 → 摇一摇发送 → 打开
  之后在本应用任何页面摇一摇手机 → 直接进入手势界面

六、隔空手势操作详解
----------------------------------------------------------------
进入手势界面后（背景是你的前摄画面）：

  第 1 步  手持手机距离面部 20~40 厘米，向屏幕张开手掌
           → 提示变为「已识别手掌」，说明相机已锁定你的手

  第 2 步  握拳 → 振动一下，提示「已抓住！」
           （此时内容已抓在手里）

  第 3 步  保持握拳，手腕左右侧倾手机 → 雷达上切换目标设备
           （也可直接点按设备卡片切换；每台设备标有通道徽标：
            「互传联盟」= 原生互传设备，「局域网」= 装了本应用
            的设备）

  第 4 步  对准目标后张开手掌 → 振动，开始发送
           → 进度显示发送百分比，完成后提示「发送成功」

  额外说明：
  - 张开手掌且手里没有内容时 = 「张掌即收」：此时若有别人发来
    的传输请求，会自动接收（可在设置关闭）
  - 手势界面最长停留到你自己退出为止；退出界面摄像头立即关闭
  - 阶段提示顺序：向屏幕张开手掌 → 已识别手掌 → 已抓住 →
    正在释放 → 发送成功/失败
  - 误识别保护：每个姿势需保持约 0.5 秒才生效，快速乱晃无效

七、看图即手势（测试版功能）
----------------------------------------------------------------
作用：当你在【其他应用】里看图片或挑文件时，自动弹出一个悬浮条，
点按即可直接进入手势界面发送，不用来回切应用。

开启方法：
  1. 设置 → 「看图即手势」→ 打开开关
  2. 首次开启会依次引导：
     a. 悬浮窗权限（显示在其他应用上层）→ 允许
     b. 无障碍服务 → 在列表找到「手势互传」→ 里面的
        「看图即手势」服务 → 开启 → 允许
     c. 小米手机额外：设置 → 应用管理 → 手势互传 → 权限 →
        后台弹出界面 → 允许（或经「设备兼容（测试版）」入口）
  3. 返回应用后开关自动变为已启用

支持的触发场景（持续扩充）：
  - 系统相册（小米/OPPO/三星/Google 相册等）
  - 微信图片浏览、聊天图片选择
  - QQ / TIM / QQ 轻聊版的图片预览、相册多选
  - 系统文件选择器、常见文件管理器

使用方法：
  在上述场景看到图片时，屏幕顶部会弹出
  「🖐 图片/文件模式 · 点按开始手势发送」
  → 点按它 → 手势界面覆盖在当前应用上 → 选择文件 → 做手势
  → 发送完成自动返回原界面
  （悬浮条 8 秒不点自动消失；同一界面 10 秒内不会重复打扰）

隐私说明：摄像头和识别算法只在你点按悬浮条之后才启动；
其余时间只运行一个极轻量的窗口监听，不调用摄像头。

八、接收对方发来的文件
----------------------------------------------------------------
情况一：对方是小米/OPPO 等原生互传
  对方在你附近发送时，你的手机会弹原生互传接收框 → 接受即可
  （需要你开启应用首页的「后台接收」开关 + 授权完整）

情况二：对方也装了手势互传（局域网通道）
  对方发送时，你的手机弹出接收面板 → 点「接受」
  - 文件保存到 Download/Easy Share（或你设置的自定义目录）
  - 对方发的是文本 → 自动复制到你的剪贴板

情况三：你正开着手势界面
  对方的请求出现时，张开手掌（手里没内容）→ 自动接收
  也可以像平时一样点「接受」按钮

----------------------------------------------------------------
九、两种传输通道的区别
----------------------------------------------------------------
                          互传联盟           局域网
  对方需要装本应用        不需要             需要（双方都装）
  网络要求             Wi-Fi+蓝牙         同一 Wi-Fi / 热点
                        Wi-Fi Direct 直连   普通 TCP 直传
  发送端额外设置        Shizuku 授权一次    无
  适用场景              给原生互传手机发    没开蓝牙/想走局域网

设备雷达会同时列出两类设备并标注通道，同一台设备不会重复出现
干扰选择。接收方与本应用互传时，自动选用对应的接收流程。

十、设置项逐条说明
----------------------------------------------------------------
【首页】
  后台接收开关        开启后应用退到后台也能接收（推荐开启）
  隔空手势传输卡片    进入手势界面（方式一入口）

【设备兼容（测试版）】
  · 显示自动识别的你的系统（如 澎湃OS 2.0 / ColorOS / HarmonyOS）
  · 自启动设置        跳转系统自启动管理
  · 电池优化          申请忽略电池优化
  · 后台弹出界面      仅小米/澎湃OS 显示
  ※ 测试版：个别 ROM 版本入口可能跳转失败，会自动退回应用详情页

【手势】
  张掌即收            手势界面里张掌自动接收请求（默认开）
  摇一摇发送          应用内摇一摇进手势界面（默认关）
  振动反馈            抓取/释放时振动（默认开）

【局域网通道】
  通过 Wi-Fi 局域网传输（默认开）——关闭后雷达只显示互传联盟设备

【设备兼容（测试版）之外的通用项】
  设备名 / 设备品牌   对方看到的你的名字与图标
  保存到              接收文件的目录
  增强模式            Shizuku（互传联盟发送需要）
  安全互传            仅接收安全协议传输（默认关）
  调试日志            导出日志用于反馈问题

十一、常见问题排查（FAQ）
----------------------------------------------------------------
Q1 手势界面黑屏 / 提示相机不可用？
  1.1 确认已授予相机权限（设置 → 应用 → 手势互传 → 权限）
  1.2 确认安装的是 1.3.3-beta 以上版本（旧版有已知黑屏缺陷）
  1.3 其他应用占用相机（如微信视频）时暂时无法绑定，关闭后重试
  1.4 强逆光环境识别率下降，换角度即可

Q2 悬浮条不弹出（看图即手势）？
  2.1 检查悬浮窗权限是否已允许
  2.2 小米手机检查「后台弹出界面」权限（见第七节开启方法 c）
  2.3 检查无障碍服务是否仍处于开启状态（系统更新后可能被重置）
  2.4 相册内连续看图每次都会触发；同一画面 10 秒内只提示一次
  2.5 某些小众 App 暂不在识别范围内，欢迎反馈包名

Q3 对方（OPPO 原生互传）显示接收失败但文件收到了？
  这是互传联盟协议的已知兼容问题，文件实际已保存到对方
  Download/Easy Share，可直接忽略提示。

Q4 发送端提示需要 Shizuku？
  只有「互传联盟通道」发送才需要。按第四节的 Shizuku 步骤操作；
  或者改用「局域网通道」（双方都装本应用即可）。

Q5 后台接收被杀？
  完成三个设置：自启动允许 + 电池优化忽略 + （小米）后台弹出
  界面允许；并在首页打开「后台接收」。

Q6 局域网里搜不到对方设备？
  6.1 确认两台手机在同一 Wi-Fi 或同一热点下
  6.2 双方的「局域网通道」开关都已打开
  6.3 部分路由器开启了 AP 隔离（禁止设备互访），需在路由器关闭
  6.4 首次发现需要 1~2 秒（每秒广播一次）

Q7 文本发过去对方哪里看？
  局域网通道的文本会直接进入对方剪贴板，长按任意输入框粘贴
  即可；接收面板会提示「文本已复制到剪贴板」。

Q8 鸿蒙 4.2 装不上？
  关闭「纯净模式」后再装（见二-1）。纯血鸿蒙 NEXT/5.0 无法安装
  任何 APK，无解。

Q9 覆盖安装失败 / 提示签名不一致？
  不同次构建使用不同临时签名，先卸载旧版再安装新版。

十二、已知限制
----------------------------------------------------------------
1. 摇一摇目前只在应用自己的界面内生效
2. 隔空手势对强逆光较敏感
3. QQ/微信的识别基于窗口特征，版本更新可能需要补充特征
4. 向 OPPO 原生互传发送时对方可能提示失败但实际成功
5. 纯血鸿蒙（HarmonyOS NEXT/5.0）不支持
6. 摄像头指示灯在手势界面期间会亮起（系统隐私机制，属正常）

版本号 + 复现步骤；可在应用内「调试日志」导出日志一并反馈。
